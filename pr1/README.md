# Карточка товара со счётчиком (лабораторная работа №1)

Мини-приложение на React: каталог из четырёх товаров, у каждой карточки есть
кнопка «Добавить в корзину» и собственный счётчик количества.

## Структура

```
pr1/
├── index.html                        точка входа страницы
├── src/
│   ├── main.jsx                      монтирование <App /> в #root
│   ├── App.jsx                       массив товаров, передача данных через props
│   ├── App.css                       стили каталога
│   ├── index.css                     общие стили страницы
│   └── components/
│       ├── ProductCard.jsx           карточка товара, счётчик на useState
│       └── ProductCard.css           стили карточки
└── package.json
```

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется по адресу, который выведет Vite (по умолчанию http://localhost:5173/).

## Остальные команды

- `npm run build` — production-сборка в папку `dist`
- `npm run preview` — локальный просмотр production-сборки
- `npm run lint` — проверка кода линтером ESLint
