## Лабораторная работа №1 «Карточка товара со счётчиком на React»

### Задание

1. Создать React-проект (Vite) и компонент `ProductCard`, который получает через props
   название товара, цену и изображение.
2. Добавить в `ProductCard` кнопку «Добавить в корзину» со счётчиком: при каждом нажатии
   количество увеличивается на 1, текущее количество отображается на карточке.
3. Для хранения количества использовать хук `useState` внутри `ProductCard`.
4. В компоненте `App` вывести несколько карточек товара с разными данными,
   передавая их через props.
5. Проверить, что счётчик каждой карточки работает независимо от остальных.

### Как устроено приложение

- `src/App.jsx` — корневой компонент. Хранит массив товаров (`id`, `name`, `price`, `image`)
  и с помощью `map()` рендерит по одной карточке `ProductCard` на каждый товар,
  передавая данные через props.
- `src/components/ProductCard.jsx` — компонент карточки. Принимает props `name`, `price`,
  `image` и объявляет собственное состояние `const [count, setCount] = useState(0)`.
  Так как `useState` вызывается внутри компонента, React создаёт отдельную ячейку состояния
  для каждого экземпляра карточки — поэтому счётчики независимы друг от друга.
- Обработчик `handleAdd` по клику вызывает `setCount(count + 1)`, и React перерисовывает
  только ту карточку, состояние которой изменилось.

Использованы только функциональные компоненты и хуки, без классовых компонентов
и сторонних библиотек управления состоянием.

## Запуск проекта

Нужен установленный [Node.js](https://nodejs.org/) версии 20 или новее.

```bash
cd pr1
npm install     # установка зависимостей
npm run dev     # запуск сервера разработки
```

После запуска приложение открывается по адресу, который выводит Vite
(по умолчанию http://localhost:5173/).

Другие команды:

```bash
npm run build     # production-сборка в папку dist
npm run preview   # локальный просмотр production-сборки
npm run lint      # проверка кода линтером ESLint
```
